# 长篇连载小说创作工作流

[中文](fiction.md) · [English](fiction.en.md)

**公开源码与示例 · 工作流设计与维护**

把创作拆成规划、确认、正文、独立检查与状态更新，保持作者对剧情和人物的控制。

```text
固定事实 -> 执行卡确认 -> 正文／独立检查 -> 更新连续状态
```

## 业务问题

长对话创作容易遗忘事实、擅改人物决定、把规划语言写进正文，或让一次修改污染长期状态。

## 实现方式

文件化事实与连续状态；正文只接收最小资料包和场景执行卡；独立 Skill 提供 chapter-planning、prose-writing、readonly-diagnosis 三种模式。完整工作流另设轻检与条件修正阶段。

## 关键取舍

一次调用只执行一种模式；先确认再写作，轻检通过后才更新正式正文与连续状态。独立 Skill 不会自动读取历史章节，也不是一键生成整本书。

## 我的贡献

将创作约束整理为输入契约、执行模式、确认门、检查规则、迁移说明与可复用模板。
