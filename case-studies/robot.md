# 桌面智能机器人

[中文](robot.md) · [English](robot.en.md)

**进行中的学术项目 · 两人团队负责人**

将控制、动作、感知与语音交互模块整合到桌面设备，并逐模块定位问题。

```text
控制 -> 动作 -> 传感 -> 语音交互
```

## 业务问题

多模块设备的问题可能来自控制参数、硬件连接或配置；需要在整机中定位，而不是盲目更换部件。

## 实现方式

参与 STM32 控制开发，集成 ESP32、舵机、语音识别、显示与传感器，协调结构装配及整机联调。

## 关键取舍

对舵机抖动检查 PWM 参数与控制逻辑；对语音识别不稳定排查 ESP32 配置。保留问题定位路径，而不只描述最后修好了。

## 我的贡献

负责项目拆解、分工、模块集成与软硬件联合调试。

## 结果与口径

展示嵌入式基础与系统集成实践。项目仍在进行，不包装成量产产品或高级嵌入式开发资历。
