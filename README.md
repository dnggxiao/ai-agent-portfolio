## 先看核心案例

### 四平台统一财务报表系统

**WB / Wildberries · Amazon · Mercado Libre · Walmart**

连接 WB、Amazon、美客多与 Walmart 的平台文件，统一人工补充／调整输入和最终报表输出，在本地工作区完成可复核的月度核算。

```text
平台原始文件 + 统一人工补充 / 调整
                         |
                 映射 - 核算 - 对账
                         |
                    标准财务报表
```

**我负责:** 负责原流程拆解、四平台输入接口、统一人工补充标准、最终报表结构、业务规则、异常边界、验收和迭代；Codex 辅助实现、重构与调试。

**结果口径:** 将四个平台的重复报表工作组织为统一标准下的自动化流程。约 15 个工作日是原月度工作量的项目估计；未提供逐月耗时对照，因此不作为精确净节省值。
