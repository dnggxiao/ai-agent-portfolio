# Desktop Intelligent Robot

**Role:** Project Lead, 2-person team  
**Status:** Ongoing academic / innovation project  
**Core stack:** STM32 · ESP32 · Keil5 · PWM · servos · voice recognition · sensors

## Project Goal

Build a desktop intelligent conversational robot that combines embedded control, motion, sensing and voice-interaction modules in one integrated system.

## My Responsibilities

- led project decomposition and task allocation;
- participated in STM32-based control-system development;
- integrated ESP32, servos, voice-recognition, display and sensor modules;
- supported shell / mechanical integration and whole-machine assembly;
- coordinated debugging across software configuration and physical components.

## Debugging Examples

The project emphasized module-by-module troubleshooting rather than replacing components blindly.

### Servo jitter

Observed symptom: unstable servo motion / jitter.  
Debugging path: isolated the issue to **PWM parameters and control logic**, then adjusted configuration and control behavior.

### Voice-recognition instability

Observed symptom: inconsistent recognition behavior.  
Debugging path: isolated the issue to **ESP32 configuration**, then corrected the relevant setup and continued system-level validation.
